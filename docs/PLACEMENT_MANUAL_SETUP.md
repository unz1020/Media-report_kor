# 날짜별 인사이트와 지면 수동 세팅

- 개요와 리포트 화면에서 날짜를 선택해 해당 날짜의 인사이트 전체를 조회한다. 동일 날짜에 여러 메일이 있으면 모두 표시한다. 메일만 저장된 날짜도 Excel 데이터 유무와 관계없이 볼 수 있다.
- 소재 · 게재지면 화면의 지면 수동 등록으로 보고서 수신 전에 지면별 소재, 미리보기 URL, 이미지, 랜딩 URL, UTM을 저장한다. 운영안의 세팅 추가 버튼으로 매체·상품·기간을 가져올 수 있다.
- 기본 상태는 사전 세팅이며 실제 게재 확인을 선택할 때에는 확인일을 입력한다.
- 기존 UTM이 포함된 전체 랜딩 URL을 받을 수 있다. 별도 입력한 5개 UTM 값은 같은 이름의 기존 쿼리를 덮어쓰며 다른 쿼리와 hash는 유지한다. 기존 UTM 삭제는 랜딩 URL에서 해당 쿼리를 제거한다.
- PNG/JPG/WEBP 이미지는 8MB까지 업로드 가능하다. 원본 이미지 저장소는 비공개이고 광고주 접근 권한 확인 후 5분 서명 URL을 발급한다.
- 기존 report_imports의 metadata.bundle.placementProof 구조를 활용한다. 새로운 수동 항목은 other source_type, 월 1일 고정 report_date, UUID source_file을 사용하며 성과 Fact로 합산하지 않는다. 원본 보고서의 지면을 수정할 때 원본 첨부와 이미지를 보존한다.
- 서버는 Google의 검증된 이메일과 활성 workspace 사용자, 광고주별 owner/editor 권한을 확인한다. viewer는 조회만 가능하다. 메타데이터 변경은 updated_at으로 충돌을 검사하고 기존 버전 보관 trigger를 유지한다. 이미지도 새 경로로 저장해 과거 버전 이미지를 보존한다.
- 지면 정보 저장과 이미지 업로드는 순차 요청이다. 이미지 업로드 실패 시 지면 정보는 유지하고 UI에서 오류와 재시도 방법을 표시한다. 네트워크 재시도는 폼별 UUID를 재사용한다.
- 자동 Gmail 수집은 기존 검수·반영 흐름을 사용한다. 이 변경은 새로운 수집 스케줄이나 광고 매체 API를 생성하지 않는다.
