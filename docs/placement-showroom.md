# Placement showroom

A read-only projection of the selected advertiser/month above the existing management tools. Storage and reporting totals are unchanged.

## Display hierarchy

- OOH / physical spaces: outdoor, cinema, elevator/living spaces and transit. TV in a vehicle or elevator is not broadcast TV.
- TV / OTT: broadcasters, addressable TV and OTT. A buying platform's publisher name does not reclassify its inventory.
- Digital: app/web placements with explicit PC/mobile/mixed/unknown device states. Mockup selection is not an assertion of actual device delivery.
- Unknown records remain available rather than silently becoming digital.

An ADVoost mixed-package proof can yield site-level exploration views only from its explicit source-photo metadata. All children still reference the same source proof. Package-level metrics stay separate; children never inherit a divided or repeated parent total.

The isometric city is a conceptual scene, not surveyed coordinates, route coverage or installation coverage. Cinema, elevator and transit use different physical context frames. Captured evidence is not live broadcasting or independent confirmation of current delivery.

## Evidence

Full-screen viewing reuses the existing authenticated image URL and viewer. For an explicitly documented two-column contact sheet with matching aspect ratio, the explorer can display the selected original page using CSS cropping. It never modifies the stored image; the full original is always available. Unsupported layouts fall back to the full source.

## Optional inventory-level performance

An editor can upload a matching monthly workbook to the review-only breakdown parser. It discovers inventory headers and date columns, ignores blank template rows and off-scope dates, preserves missing values, and keeps foot traffic separate from reported counts. Paid cost excludes service inventory; reported count validation includes service inventory. A mismatch blocks publication.

After explicit review, the uploader stores a separate augmentation dataset (`sourceKind: showroom_breakdown`) with empty placements, daily performance and media-plan arrays. Existing monthly totals, daily facts, proof records and operating plans are not replaced. Only the creative showroom consumes the additional breakdown metadata. Original workbook bytes are never sent by this workflow.

Regression fixtures are synthetic. Never commit private reports, raw mail, client data snapshots, image files, credentials, or local preview authentication mocks.
