## UI rules
1. Never show source file/sheet as the primary hierarchy.
2. Performance primary navigation is Media → Product.
3. Source file/sheet stays visible only as a traceability detail.
4. Mail body is rendered as dated operating insight for the matching media/product, not as free-floating text.
5. Product-specific KPI columns are shown only when present in the source.
6. Alias normalization happens before grouping and filters.
